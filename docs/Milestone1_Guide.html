Part 3. How the engine works

3.1 The board and the score

The board is a 4×4 list of numbers, and 0 means an empty cell. The score goes up by the value of every tile created by a merge.

3.3 The other three directions reuse the same function

DirectionTrick
LeftSlide each row as is
RightReverse each row, slide left, reverse back
UpTranspose (rows become columns), slide left, transpose back
DownTranspose, reverse, slide left, reverse, transpose back

Worked example, move_board(board, LEFT) on the first row [2,0,2,4] returns the row [4,4,0,0] and score gain 4, as checked in the run above.

3.5 Random tiles, seeds, and game over

IdeaIn plain words
New tileAfter a valid move, a 2 (90%) or a 4 (10%) appears in a random empty cell.
SeedGame2048(seed=2048) fixes the randomness, so the same moves give the same game. This lets us compare agents fairly in Milestone 4.
Game overNone of the four directions changes the board. A full board with a possible merge is not over.
game = Game2048(seed=2048)
game.move(LEFT)             # True if legal
game.get_legal_moves()      # e.g. ['up', 'down', 'left', 'right']
game.get_state()            # board copy, score, game_over, highest_tile
Why move_board is separate: it changes nothing and spawns no tile. In Milestone 2, Expectimax will call it to try moves safely, then add its own chance nodes for the random tile.
